# Storyboard

Write storyboard/scenes.json from the edited transcript and resolved notes. See examples/jev/storyboard.json. It is an agent-authored editorial artifact; the CLI does not auto-generate visuals or invent Jev facts. Reference clip IDs, source/output ranges and timeline revision. Reference word IDs only where measured word timing exists; segment precision must remain explicit.

Commands run from the toolkit root; `video.py` means `python3 scripts/video.py`.

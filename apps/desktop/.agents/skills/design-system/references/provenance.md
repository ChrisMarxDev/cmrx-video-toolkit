# Provenance

Conceptual source: “Build the design system and skills your agent can follow”,
by @_heyrico, linked by Christopher at
<https://x.com/_heyrico/status/2116953958279479760>.

The URL returned HTTP 403 during retrieval. Christopher supplied the article text
in conversation on 2026-11-09; that text is the basis for this adaptation. The
embedded video was not inspected.

This is newly written guidance based on the article's five-layer approach:
primitives, semantic foundations, components, blocks, and rules/task skills.
The article and its code examples are not bundled. No redistribution license for
the original article is asserted.

Local adaptations:

- Use the consuming product's existing stack, token format, and documentation.
- Separate implemented, approved, proposed, and unresolved decisions.
- Treat example palettes, shadcn/ui, component lists, and product rules as examples.
- Add implementation evidence, accessibility, responsive behavior, transition
  verification, and explicit limits on unperformed visual checks.
- Offer documentation records and a screen-review procedure without requiring a
  second generated skill or runtime-specific installation.

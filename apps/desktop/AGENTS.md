# Desktop app development

Follow the toolkit root AGENTS.md. For Mac build/sign/notarize/release tasks, read
`.agents/skills/desktop-deploy/SKILL.md`. That app-maintenance skill is versioned
with this app; it is not part of the creative agent's `skills/` directory or the
toolkit's root creator catalog. Standalone deployment needs no private repository.

Read README.md, WORKSPACES.md and RELEASING.md for current behavior and limits.
Use synthetic fixtures, retain source provenance and keep credentials/test profiles
out of Git. A release skill does not imply that the current source is Mac-ready.

For app design-system work, read `.agents/skills/design-system/SKILL.md` and
`DESIGN.md`. Keep implemented behavior, approved rules and interview proposals
separate. This skill is app-development guidance, not an installed video-project
skill; do not change generated-video styles while restyling the app.

For app buttons, chat and surface hierarchy, follow the concise rules in DESIGN.md.
Prefer imagery, visual affordances and familiar shortcuts to persistent instruction
copy. Preserve accessible names, hover labels and explicit recovery/decision text.

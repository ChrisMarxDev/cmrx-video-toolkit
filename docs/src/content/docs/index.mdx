Use the toolkit to review a recording’s transcript, choose cuts, add captions and
animations, and render a video. Python and FFmpeg handle media processing;
Flutter renders the visual elements. Agent skills describe how to run each stage.

## Before you begin

The toolkit runs on your computer and is in early development. Review the rough
cut before building animations. Keep original recordings unchanged and check the
final render. Store recordings, transcripts and generated media outside Git.

Set your video colors and typography through the component styling API.

[Source code on GitHub](https://github.com/ChrisMarxDev/cmrx-video-toolkit)

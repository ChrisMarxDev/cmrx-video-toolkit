A collection of **agent skills, tools and reusable video components**, with
`edit-video` as the core editing experience. Make a complete video or pick the
piece you need: visual style, component authoring, animation, 3D or effects.

Your agent works with footage, transcripts and editable Flutter scenes. You
review the cuts and visuals, request changes and approve the export.

**[Start editing →](/cmrx-video-toolkit/guides/quick-start/)**

**[Browse the skills & tools glossary →](/cmrx-video-toolkit/reference/skills/)**

## One workflow, a useful collection

**Bring footage or assets → shape the edit → compose scenes → review live → export.**

`edit-video` coordinates this workflow and loads only the guidance needed at each
stage. Other skills can help with a specific task without starting a full edit.

## Before you begin

The toolkit is in early development. Installing skills adds guidance, not the
runtime tools, models or MCP registrations. Your agent prepares the requirements
for the chosen workflow; the quick start also covers manual setup.

Bring your own colors, fonts and editorial direction. Keep original recordings
unchanged, review the composition before export and check the final render.
Store production media outside Git. Optional generation services have their own
credentials and terms; the local media tools do not require generation keys.

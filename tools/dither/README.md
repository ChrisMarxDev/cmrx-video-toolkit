# Dither studio

Open index.html locally. Generate ordered fields or transform an image entirely
on your computer; export PNG/settings. No uploads. Default swatches are examples.
Rebuild after editing app.js: `npx esbuild@0.25.12 app.js --bundle --format=iife --outfile=app.bundle.js`.
Run `node --test core.test.mjs`. Native Flutter dithering is in design_system/.

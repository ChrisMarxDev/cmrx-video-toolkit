# Video Dithering

Use DitherPrograms, DitherField, DitherImage and DitherStyle. Preload once. The
original native Bayer algorithm supports 2/4/8 matrices; start at 1 output pixel,
explicit outputScale and fixed grid. Animate density with output seconds. Preserve
source alpha and keep foreground content readable. Use the workspace palette; do
not impose CMRX styling. Paper is a research reference, not pixel/API-equivalent.
Inspect the compressed output; fine patterns can shimmer or disappear.
